# Retro Launcher

Android için 3310 tarzı ana ekran: yeşil ekran, hiç kaybolmayan tuş takımı.

**İndir:** https://github.com/HiranaHrn/retro-launcher/releases/latest/download/RetroLauncher.apk

## Kullanım
- Ekrandaki ikona dokun: uygulama açılır. Basılı tut: uygulama bilgisi.
- Sağa/sola kaydır: sayfa değişir.
- Oklar: seçimi kaydırır. Orta tuş: seçili uygulamayı açar.
- Rakam tuşları: numara yazar. Orta tuş: arar.
- C: siler. Basılı tut: numarayı temizler.
- `*` veya `0` basılı tut: `+` yazar.
